Meldet <exclusion>-Einträge in der pom.xml, die nichts mehr ausschließen – typisch nach einem Upgrade der Dependency (Maven Detective, Modul A4).

Maven Detective baut den transitiven Baum der Dependency aus den POMs im lokalen Repository nach, und zwar ohne die geprüfte Exclusion. Taucht das ausgeschlossene Artifact darin nicht auf, ist die Exclusion veraltet. Kommt es nur über einen Pfad, den eine andere Exclusion derselben Dependency schon kappt, ist sie doppelt.

Fehlen unterwegs POMs im lokalen Repository, meldet die Inspection nichts – lieber keine Meldung als eine falsche. Einmal bauen, dann prüft sie vollständig. Projektweit: Code | Inspect Code oder maven-detective-core.jar exclusions.

Quick-Fix: Exclusion entfernen (bei der letzten samt <exclusions>).
